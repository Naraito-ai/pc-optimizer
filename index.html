Core Features
Automated tuning for max performance.
🧠
Memory & RAM Flush
Instantly flushes standby RAM working sets and safely terminates known bloatware processes (OneDrive, Teams, Cortana, etc.) consuming memory.
🗑️
Deep Junk Removal
Cleans Windows Temp, System Temp, Prefetch, Windows Update cache, and Chrome / Edge / Firefox browser caches automatically.
⚖️
Smart Power Plan
Applies the Balanced power plan — boosts CPU when needed, scales back at idle. Prevents the overheating caused by High Performance mode.
🚀
Startup App Optimizer
Identifies and removes unnecessary apps loading on Windows startup — dramatically cuts boot time while keeping security tools safe.
🔧
Telemetry & Service Tweak
Disables non-essential background services (DiagTrack, SysMain, WSearch) for improved privacy and reduced disk/CPU overhead.
🌐
Network & TCP Reset
Flushes DNS cache, resets Winsock catalog, resets IP stack, and optimizes TCP auto-tuning for improved network responsiveness.
Installation
Choose your preferred method.
iwr -useb https://raw.githubusercontent.com/Naraito-ai/pc-optimizer/main/install.ps1 | iex
  • 1
    Press Win + X → click Windows PowerShell (Admin) or Terminal (Admin)
  • 2
    Paste the command above and hit Enter
  • 3
    The script auto-installs Python if needed, downloads the optimizer, and runs it automatically

✅ No files are permanently installed. The script runs from a temp folder and cleans up after itself.

optimizer.exe — Windows x64 · No Python required · ~9 MB
⬇ Download EXE
  • 1
    Click Download EXE above — the file downloads directly to your browser's Downloads folder
  • 2
    Right-click optimizer.exe → Run as Administrator (or double-click — it will prompt for admin automatically)
  • 3
    Click Yes on the UAC popup. A terminal window opens and optimization runs automatically

⚠️ Windows SmartScreen may show a warning on first run — click More info → Run anyway. The code is fully open-source on GitHub.

Safety & Protection
Built with strict safety guardrails.
✓
System Restore Point First
Creates a native Windows Restore Point before any system modifications — you can always roll back.
✓
Critical Process Shield
System processes (svchost, lsass, winlogon, explorer, dwm) are hardcoded as untouchable — never terminated.
✓
No Overclocking or Overheating
Uses the Balanced power plan — not High Performance — so your CPU stays cool and won't thermal throttle.
✓
Security Tools Protected
Startup items matching Defender, antivirus, Realtek, NVIDIA, AMD, Intel, and Bluetooth are never disabled.
✓
Before / After Report
Shows a detailed RAM, CPU, and disk comparison table so you can see exactly what changed.
✓
100% Open Source
Every line of code is on GitHub. Read it, audit it, or fork it — full transparency guaranteed.
