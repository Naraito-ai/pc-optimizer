Core Features
Smart, targeted optimizations only.
🗑️
Deep Junk Removal
Deletes Windows Temp, System Temp, Prefetch cache, Windows Update download cache, and Chrome / Edge / Firefox browser caches.
🔕
Telemetry Killer
Stops and disables DiagTrack (Connected User Experiences & Telemetry) — the background service that sends usage data to Microsoft.
🚀
Startup Optimizer
Scans registry startup entries and removes non-essential apps from boot. Security tools, GPU drivers, and antivirus are always protected.
⚖️
Balanced Power Plan
Ensures your PC uses the Balanced power profile — boosts CPU when needed, scales back at idle. Prevents the overheating caused by High Performance mode.
🌐
Network Stack Reset
Flushes DNS cache, resets Winsock catalog, resets IP stack, and tunes TCP auto-tuning. Fixes network issues and reduces ping after a restart.
🖥️
Visual Effects Trim
Disables Windows animations and visual transitions that waste GPU cycles — makes UI feel snappier without any visible quality loss.
Safe by Design
What this tool does — and does NOT do.
✅
Uses Balanced Power Plan
High Performance forces your CPU to 100% clock speed non-stop → heat → thermal throttle → lag. We use Balanced instead.
✅
Superfetch (SysMain) stays ON
SysMain pre-loads your frequently used apps into spare RAM. Disabling it means every app launch hits the disk cold — making everything feel slower.
✅
No RAM Working Set Flush
EmptyWorkingSet on hundreds of processes dumps RAM to the pagefile on disk — causing 5–15 minutes of disk thrashing and stuttering. We don't do this.
✅
No Registry Overclocking
We don't touch CPU PowerThrottling or any registry keys that disable Windows' built-in thermal management.
✅
System Restore Point First
Creates a Windows Restore Point before making any changes. If anything goes wrong, you can roll back completely.
✅
Critical Processes Protected
svchost, lsass, winlogon, explorer, dwm and all other system-critical processes are hardcoded as untouchable.
Installation
Two ways to run it.
iwr -useb https://raw.githubusercontent.com/Naraito-ai/pc-optimizer/main/install.ps1 | iex
  • 1
    Press Win + X → Windows PowerShell (Admin) or Terminal (Admin)
  • 2
    Paste the command above and press Enter
  • 3
    Script installs Python if needed, downloads the optimizer, and runs it automatically with [AUTO] mode

✅ No permanent install. Runs from a temp folder and cleans up after itself.
