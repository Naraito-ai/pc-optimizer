What it does
Every optimization, automated.
🧠
Memory cleanup
Flushes standby RAM, kills idle bloatware like OneDrive, Teams, Cortana, and Discord running in the background.
🗑️
Junk file removal
Clears temp folders, browser caches (Chrome, Edge, Firefox), and leftover Windows Update files. Typically frees 1–10 GB.
⚡
CPU & power boost
Switches to High Performance power plan, disables CPU throttling, and turns off Windows animations and visual lag.
🚀
Startup manager
Lists every app that launches at startup and lets you disable the ones you don't need — cutting boot time by 10–40 seconds.
🔧
Services optimizer
Stops and disables non-critical Windows background services like SysMain, DiagTrack (telemetry), and WSearch.
🌐
Network tweaks
Flushes DNS cache, resets Winsock, and tunes TCP settings for faster browsing and lower ping.
How it works
Simple. Safe. Fast.
1
Creates a restore point
Before touching anything, the tool automatically creates a Windows System Restore Point. One click undoes everything if needed.
2
Runs all optimizations
Memory, disk, CPU, services, startup, and network — all handled automatically in sequence. Risky operations ask for your confirmation first.
3
Shows you the results
A clean before/after report shows exactly how much RAM was freed, how much disk space was cleared, and how your CPU load changed.
4
Done — your PC runs cleaner
No restarts required for most optimizations. Noticeable difference in snappiness, boot time, and app launch speed immediately.
Get started
Two ways to install.
Option A — Power users
One-line install
Open PowerShell as Administrator and paste this. It installs Python if needed, downloads the tool, and launches it automatically.
iwr -useb https://raw.githubusercontent.com/Naraito-ai/pc-optimizer/main/install.ps1 | iex

Run PowerShell as Administrator (right-click → Run as administrator)

Option B — Easy mode
Download .exe
Download the standalone executable. No Python needed. Right-click and run as Administrator — one button does everything.
↓ Download optimizer.exe

If Windows shows a SmartScreen warning: click More info → Run anyway. This is normal for unsigned tools.

Safety
Built with guardrails.
✓
Restore point first. Creates a Windows restore point before making any changes.
✓
Never kills system processes. svchost, lsass, winlogon, explorer are all protected.
✓
Asks before risky actions. Service disables and startup removals require your confirmation.
✓
Safe paths only. Only deletes files from defined temp folders. Nothing else is touched.
✓
Open source. Every line of code is on GitHub. Read it before you run it.
✓
Admin check on launch. Exits cleanly with a clear message if not run as Administrator.
⚠️
PC Optimizer works best on Windows 10 and Windows 11. Windows 7/8 support is partial. Mac and Linux are not supported. A system restore point is created automatically, but use at your own discretion on production or work machines.
